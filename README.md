# Ambati Venkateswarlureddy - Portfolio

A modern, responsive personal portfolio website showcasing my profile, technical skills, education, leadership experience, awards, and recent projects.

## Highlights

- Dark and light theme support
- Responsive layout for mobile, tablet, and desktop
- Animated neural-network hero section
- Skills and progress overview
- Education and leadership timelines
- Featured project cards
- Contact details and copy-to-clipboard actions

## Featured Projects

- **ANN - Building Damage Classifier:** A deep learning project that classifies building damage severity using image data, PyTorch, and ResNet.
- **Customer Segmentation and LTV Prediction:** A machine learning project for analyzing customer behavior, identifying segments, and predicting lifetime value.
- **Student Attendance and Exam Performance Analysis:** An interactive Tableau dashboard examining the relationship between attendance and academic performance.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tableau
- Python
- Machine Learning

## Run Locally

Open `index.html` directly in a browser, or start a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
